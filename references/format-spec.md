# 广东工业大学本科生论文格式规范细则

权威来源：《广东工业大学本科生毕业设计（论文）格式规范》PDF（学校教务处/学院官网发布；本技能已收录其全部细则，如学校发布新版请以官方文件为准）。以下为已实现并经渲染验证的完整细则与 python-docx 实现要点。

## 1. 页面与版式

- 纸张 A4；页边距：上 30mm、下 25mm、左 30mm、右 20mm。
- 正文 1.5 倍行距（`line_spacing = 1.5`）。
- 页码：小五号 Times New Roman，**页脚右侧**，阿拉伯数字从**正文第 1 章**起编；封面、摘要、Abstract、目录不编页码（分节实现：`WD_SECTION.NEW_PAGE` + `sectPr/pgNumType start=1` + 页脚 `PAGE` 域）。

## 2. 标题层级

| 层级 | 格式 | 备注 |
|---|---|---|
| 章（H1） | 三号（16pt）黑体加粗，居中 | **每章另起一页**（章前分页符） |
| 节（H2） | 小四（12pt）黑体加粗，左对齐 | 段前段后 0.5 行 |
| 条（H3） | 小四黑体（可不加粗） | 段前段后 0.25 行 |

- "参考文献""附录""致谢"作无编号一级标题，同样另起一页、同 H1 格式。
- 标题必须用 Heading 样式（便于 Word 重建目录与导航窗格识别），再逐 run 强制字体。

## 3. 正文文字

- 中文小四宋体；西文/数字 Times New Roman。
- 首行缩进 2 字符：`w:ind firstLineChars="200"`（**字符单位**，勿用固定磅）。
- 两端对齐（JUSTIFY）。
- 关键结论加粗（中文加粗用宋体加粗即可，不必换黑体）。
- 术语全文统一（同一物理量符号、同一译名）。

## 4. 表格（三线表）

- 表题位于**表上方**，五号（10.5pt）黑体加粗，居中，编号"表章.序 题名"。
- 三线表：顶线、底线 1.5pt（`w:sz=12`），表头栏下线 0.75pt（`w:sz=6`），**无竖线**、无其他横线。
- 表头行设 `tblHeader`（跨页时重复表头）；各行设 `cantSplit`（行内不跨页断裂）。
- 表内文字五号；表头可加粗；单元格边距 left/right ≈ 0.1cm。
- 表格随文走："见表X.X"出现在表之前。

## 5. 插图

- 图题位于**图下方**，五号宋体，居中，编号"图章.序 题名"。
- matplotlib 出图：`figsize` 按版心宽（约 15.5cm ≈ 6.1in）设计，`dpi=300`，SimHei 中文字体 + `axes.unicode_minus=False`。
- 多子图在**每个子图正下方**标 (a)(b)(c)；图内字号 ≥8pt（缩到版心后仍可读）。
- 流程/架构图：框内多行文字块与框标题保持间距（正文块中心放 y+h*0.44 以下，必要时更低）；勿让文字贴框边。

## 6. 公式（OMML 原生）

- **必须**用 Word 原生公式对象（`<m:oMath>`，等价"插入→公式"），禁止图片、MathType OLE 或纯文本。
- 排版：公式居中、编号（章.序）右对齐。实现：段落加两个 tab stop——Cm(7.9) 居中 + Cm(15.9) 右对齐，内容为 `\t [公式] \t（2.1）`。
- OMML 构造器（见 scripts/build_report.py）：`mr`（run）、`frac`（分式）、`ssub/ssup`（下/上标）、`rad`（根号）、`dparen`（括号）、`omath`（包装，需带 m/w 命名空间声明）。
- 变量斜体、单位正文；公式中符号与正文符号一致；"式中：…"说明段紧随公式，无首行缩进。

## 7. 参考文献（GB/T 7714-2015）

- 顺序编码制：正文引用处 `[n]` **上标**（`run.font.superscript = True`），多引用 `[5-7]`/`[8,9]`。
- 文献表每条：`[n] 作者. 题名[文献类型标识]. 出版地: 出版者, 年: 页码.` / 期刊 `刊名, 年, 卷(期): 页码.`
- 类型标识：专著[M]、期刊[J]、标准[S]、报告[R]、电子资源[EB/OL]、学位论文[D]。
- 作者≤3 全列，>3 列前 3 加", 等/et al"。
- 悬挂式排版；条目五号（10.5pt）。
- 数量口径易混淆：通常"总数≥20 且**英文文献≥5 篇**"——动手前与用户确认。
- 校验：脚本提取所有上标引用号，验证与文献表 [1..N] 完全双向覆盖。

## 8. 前置部分

1. **封面**：课程名/报告类型（黑体大字）+ 信息表（题目/专业班级/姓名/学号，值单元格仅保留下框线形成下划线）+ 日期。
2. **摘要**：标题"摘　要"三号黑体居中；正文小四宋体；末行"关键词：xxx；xxx"（"关键词"黑体加粗）。
3. **Abstract**：标题 TNR 加粗居中；正文 TNR 小四；"Key words: "。
4. **目录**：标题"目　录"三号黑体居中；一级条目黑体加粗、二级缩进 0.74cm；五号（10.5pt）单倍行距、右对齐页码 + 点线引导 tab（Cm(15.9)）。
   - 用**静态目录段落**（标题仍用 Heading 样式），渲染一致性优于 TOC 域；页码由 finalize 脚本迭代回填。

## 9. 构建与校验管线（Windows 本机）

```
内容模块(report_content.py) → build_report.py(组装docx)
  → finalize_report.py(build→soffice渲染→提取标题页码→回填目录, 迭代至收敛)
  → verify_docx.py(OMML数/图片数/引用覆盖/文献数)
  → word_count.py(Word口径字数: 汉字1+西文串1)
  → render_pdf.py(逐页PNG) → 视觉抽查关键页
```

- soffice：安装 LibreOffice 后在 PATH 中直接可用；`render_pdf.py` 会自动探测（含便携版候选路径）。
- PDF→PNG：pymupdf `get_pixmap(dpi=100~110)`。
- 渲染后从 sectPr **删除 docGrid**（LibreOffice 下会撑高行距）；不要用 exact 行距控制版面（被忽略）。
- cmd 中 `python -c` 含引号/中文会静默失败：一律写脚本文件执行。

## 10. 字数口径（重要）

- 用户口中的"字数"= Word 状态栏**字数**：每个汉字计 1，每个连续西文/数字串（如 `1.081`、`kW`、`GB/T`、英文单词）各计 1。
- 统计脚本需同时报告：总字数、正文文字、表格、参考文献、目录/摘要分项。
- 课程报告"3000 字以上"类要求 → 目标落在要求的 1.3–1.8 倍；精简时优先删：附录 > 冗余文献 > 论述性重复 > 表格文字；保留思路链、核心公式、全部图表成果。

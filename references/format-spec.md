# 广东工业大学本科生论文格式规范细则

权威来源：《广东工业大学本科生毕业设计（论文）格式规范》（附件3-26，学校教务处/学院官网发布；学校发布新版时以官方文件为准）。以下细则已与手册正文及全部样张逐条核对（2026-10-24）。

## 1. 页面与版式

- A4 打印；页边距：上 30mm、下 25mm、左 30mm、右 20mm。
- 行间距 1.5 倍（`line_spacing = 1.5`）。
- 页码：**从绪论起连续编排至附录**，阿拉伯数字，**页脚右侧**，小五号 Times New Roman；封面、中英文摘要、目录**不编**页码（分节实现：`WD_SECTION.NEW_PAGE` + `pgNumType start=1` + 页脚 `PAGE` 域）。
- 文中任何部分不得超过版面；标点按 GB/T 15834-2011。

## 2. 标题层级

| 层级 | 编号式样 | 格式 | 备注 |
|---|---|---|---|
| 章 | `1` | 三号（16pt）黑体**加粗**，居中 | **每章另起一页**；标题≤15字、不得用标点 |
| 节 | `1.1` | 小四（12pt）黑体**加粗** | 段前段后各 0.5 行 |
| 条 | `1.1.1` | 小四黑体（不加粗） | 段前段后各 0.5 行 |
| 款/项 | `1、` / `（1）` | 小四宋体 | 节后可直列款、项 |

- 层次编号理工/社科类用 `1 / 1.1 / 1.1.1`，外语类用 `Ⅰ / A / a`。
- "结论""参考文献""致谢""附录A"为无编号一级标题，同样另起一页、三号黑体加粗。
- **正文之后顺序：结论 → 参考文献 → 致谢 → 附录**（样张4目录顺序）。
- 标题必须用 Heading 样式（Word 导航/目录重建依赖），再逐 run 强制字体。

## 3. 正文文字

- 中文小四宋体；数字与字母一律 Times New Roman。
- 首行缩进 2 字符：`w:ind firstLineChars="200"`（字符单位，勿用固定磅）。
- 两端对齐；关键结论加粗。
- 书写规范：量与单位按 GB3100~3102；测量统计数据用阿拉伯数字（"两颗小行星"类叙述除外）；年份写全（2005 年，不写 05 年）；缩写词首次出现括注英文全文；外国人名用原名（名前姓后，如 Weiguo Liu）；中国人名英译名前姓后。
- 注释用页末注或篇末注，不用行中注。

## 4. 表格（三线表）

- 表序按章编排（表1.1）；**表序与表名置于表上居中**，五号（10.5pt）黑体加粗，其中数字字母为五号 TNR 加粗；表名中不用标点、表名后不加标点。
- **不加左右边线**（无竖线）；顶线/底线 1.5pt（`w:sz=12`）、表头栏下线 0.75pt（`w:sz=6`）。
- 表头与表格为整体，不得拆开两页：表头行设 `tblHeader`，各行设 `cantSplit`。
- 表内文字**五号宋体**，起行空一格、转行顶格、句末不加标点。
- 全表同一单位时，单位符号移至**表头右上角**（如"表3.3 压降损失计算结果 Pa"）。
- 数字空缺的格加"—"（占2字符），不许用""/"同上"。
- 表下附注用**小五号宋体**：单条"注：…"，多条"注：1.…"，句末加标点。

## 5. 插图

- 图号按章编排（图1.1）；**图题置于图下**，五号宋体，图名在图号后空一格；引用图在图题右上角加文献号。
- **分图号 (a)(b)(c) 置于各分图之下**（五号宋体）。
- 图中各项文字说明/图注用**小五号宋体**，置于图题（或分图题）之上；图中说明用中文。
- 插图与图题为一整体，不得拆开排两页（`keep_with_next`）；当页放不下时其后文字提前、图移次页最前。
- 有数字标注的坐标图**必须注明坐标单位**；电气图符号符合国标；流程图用结构化画法。
- matplotlib 出图：版心宽约 15.5cm，`dpi=300`，SimHei + `axes.unicode_minus=False`，图内字号≥8pt。

## 6. 公式（OMML 原生）

- 手册原文"使用数学公式编辑器编写"——现代等价物即 **Word 内置公式（OMML，"插入→公式"）**，禁止图片/纯文本。
- 公式另起一行**居中**；序号加圆括号置于**右边行末**，按章编排：`(1.1)`、`(2.3)`，附录 `(A1)`；公式与编号间**不加虚线**。
- 长公式优先在等号"＝"处转行，其次在 +−×÷ 处转行，运算符号不写在转行后行首。
- 文中引用写法："见式(1.1)""由公式(1.1)"。
- 实现：段落 tab stops Cm(7.9) 居中 + Cm(15.9) 右对齐，内容 `\t [公式] \t（2.1）`；构造器 `frac/ssub/ssup/rad/dparen/omath`（scripts/build_report.py）。
- "式中：…"说明段紧随公式。

## 7. 参考文献（GB/T 7714-2015）

- "参考文献"标题居中（三号黑体加粗）作标识；**文献表正文为小四号宋体**（样张8）。
- 序号**左顶格** `[1]`，与正文指示序号一致；**每条目末以"．"结束**（半角"."或全角"．"全文统一即可）。
- 著录式样（样张8）：
  - 期刊 `[序号]作者．题名[J]．刊名，年，卷(期)：起止页码．`
  - 专著 `[序号]作者．题名[M]．出版地：出版者，年：页码．`
  - 会议 `[序号]作者．题名[A]∥主编．论文集名[C]．出版地：出版者，年：页码．`
  - 学位论文 `[D]`、报告 `[R]`、专利 `[P]`、标准 `[序号]标准代号，标准名称[S]．出版地：出版者，年．`、报纸 `[N]`、电子文献 `[EB/OL]`
- 外国作者姓名：**姓前名缩写后**（JOHNSON A, DUDA R）。
- **正文引用**：上标 `[n]` 置于所引内容**最末句右上角**（小四号）；多篇 `[3, 6-9]`；当文献编号作行文直接说明时**与正文排齐不上标**（"由文献[8, 10-14]可知"）；**不得将引用标示置于各级标题处**。
- 一篇文献多处引用时序号以第一次出现为准。
- 校验：脚本提取所有上标引用号，验证与文献表 [1..N] 双向覆盖。

## 8. 摘要与关键词

- 中文摘要："摘要"两字**三号黑体加粗**（居中，样张2）；正文小四宋体、1.5 倍行距。**字数：论文摘要约 400 字 / 设计总说明约 500 字**。
- 摘要正文后**下空一行**打印"关键词"三字：**四号黑体加粗**；关键词 **3～5 个**，按外延层次排列（外延大在前），**之间用逗号分隔，最后一个后不加标点**。
- 英文摘要**另起一页**，内容与关键词与中文一致；"Abstract"**三号 TNR 加粗**；正文小四 TNR；"Key words:"**四号 TNR 加粗**，关键词同样用逗号分隔。

## 9. 目录

- "目录"标题三号黑体加粗。
- **按三级标题编写**（1 / 1.1 / 1.1.1）；目录中标题及页码必须与正文一致（finalize 脚本迭代回填）。
- **一级标题用小四号黑体，其余各级用小四号宋体**（样张4）；阿拉伯数字用 TNR。
- 点线引导 + 页码右对齐（tab stop Cm(15.9)，DOTS leader）；用静态目录段落（标题仍用 Heading 样式），渲染一致性优于 TOC 域。

## 10. 封面与书脊

**毕业设计（论文）封面**（样张1(1)，学院指定打印社蓝色条纹纸）：
- "本科毕业设计（论文）"+ **论文题目：二号黑体加粗居中**（外语论文另起行加外文题目，小二号加粗）
- 学院 / 专业 / 年级班别 / 学号 / 学生姓名 / 指导教师：各字段**三号黑体加粗**
- 年 月：三号黑体加粗；数字字母 TNR 加粗

**书脊**（样张1(2)）：论文题目、姓名四号黑体加粗；学院名称小四黑体加粗。

**课程报告封面**（课程场景常用）：课程名/报告类型黑体大字 + 信息表（题目/专业班级/姓名/学号，值单元格仅保留下框线成下划线）+ 日期。

**外文译文封面**（样张11）：与论文封面同款字段。

## 11. 致谢与附录

- 致谢：无编号一级标题（三号黑体加粗），小四宋体正文；对直接帮助者简短致谢。
- 附录依序 A、B、C…；**附录内图、表、式单独编序**并在数码前冠附录码：图A1、表B2、式(B3)；过长的公式推导、源程序、符号说明可入附录。

## 12. 毕业设计分类型要求（字数/文献量）

| 类型 | 字数要求 | 参考文献 | 外文 |
|---|---|---|---|
| 工程设计类 | ≥15000（设计计算说明书） | ≥10 | ≥2 |
| 理论研究类 | ≥20000 | ≥15 | ≥4 |
| 实验研究类 | ≥15000 | ≥10 | ≥2 |
| 计算机软件类 | ≥10000 | ≥10 | ≥2 |
| 综合类 | ≥10000 | ≥10 | ≥2 |
| 经管文类 | ≥18000 | ≥15 | ≥2 |
| 法学类 | ≥8000 | ≥15 | ≥2 |
| 艺术类 | ≥8000 | ≥8 | ≥2 |

- **专业外文文献翻译**：20000 印刷字符或 5000 汉字以上（艺术类 5000~10000 字符 / 2000~3000 汉字），内容尽量结合课题。
- 每章标题简明（≤15字）；图纸按制图标准；参考文献数量口径以上表为准（注意：这是**毕业设计**口径，课程报告口径以任课教师要求为准）。

## 13. 构建与校验管线（Windows 本机）

```
内容模块(report_content.py) → build_report.py(组装docx)
  → finalize_report.py(build→soffice渲染→提取标题页码→回填目录, 迭代至收敛)
  → verify_docx.py(OMML数/图片数/引用覆盖/文献数)
  → word_count.py(Word口径字数: 汉字1+西文串1)
  → render_pdf.py(逐页PNG) → 视觉抽查关键页
```

- soffice：安装 LibreOffice 后在 PATH 中直接可用；`render_pdf.py` 自动探测（含便携版候选路径）。
- PDF→PNG：pymupdf `get_pixmap(dpi=100~110)`。
- 渲染后从 sectPr 删除 docGrid（LibreOffice 下会撑高行距）；不要用 exact 行距（被忽略）。
- cmd 中 `python -c` 含引号/中文会静默失败：一律写脚本文件执行。

## 14. 字数口径（重要）

- 用户口中的"字数"= Word 状态栏**字数**：每个汉字计 1，每个连续西文/数字串各计 1。
- 课程报告"3000 字以上"类要求 → 目标落在要求的 1.3–1.8 倍；精简优先级：附录 > 冗余文献 > 论述性重复 > 表格文字；保留思路链、核心公式、全部图表成果。
